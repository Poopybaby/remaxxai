Getting started / Install

Install Quill

Quill is a plain-text notes app that keeps everything in a folder you choose. Install it with your package manager of choice.

npm install -g quill-notes
Note Quill needs read and write access to the folder you pick. It never uploads anything unless you turn on sync.

Configuration

Create a quill.toml in your notes folder:

folder = "~/notes"
theme = "paper"
autosave_seconds = 5

Your first note

Run quill new "Groceries". The file opens in your editor and appears in the sidebar.
